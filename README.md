# Container Loading Optimizer

A runnable demo web application that accepts container and package dimensions and generates a 3D packing visualization showing used and remaining space.

## Features
- Container length/width/height and max weight
- Multiple package types
- Quantity, weight, color, importance, auto-rotate
- Simple 3D bin-packing heuristic
- Interactive 3D visualization with Three.js
- Space utilization, residual volume, unpacked volume/items

## Run
1. Install Python 3.10+
2. `pip install -r requirements.txt`
3. `python app.py`
4. Open `http://127.0.0.1:5000`

This is an original demo implementation inspired by the functionality shown in the supplied screenshots; it is not the source code of the pictured website.
